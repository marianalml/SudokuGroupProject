# Sudoku Game

## Overview

This project is a Sudoku game developed in Python using Pygame. The application generates playable Sudoku puzzles with an interactive graphical interface that allows users to solve the puzzle by entering numbers directly into the game board.

This project was completed as a four-person team project for a programming course.

## Features

- Interactive Sudoku board
- Automatically generated puzzles
- User input validation
- Win detection
- Graphical interface using Pygame

## Technologies Used

- Python
- Pygame
- Object-Oriented Programming
- Git & GitHub
